# social_auth_core_android

Implementación Android de [`social_auth_core`](../social_auth_core): abre el inicio de sesión en una Custom Tab y entrega el redirect a Dart.

No la agregues a mano: `social_auth_core` la trae. La configuración (esquema del redirect) está en [doc/android.md](../social_auth_core/doc/android.md).
