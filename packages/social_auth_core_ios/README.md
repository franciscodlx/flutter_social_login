# social_auth_core_ios

Implementación iOS de [`social_auth_core`](../social_auth_core): abre el inicio de sesión con `ASWebAuthenticationSession` y entrega el redirect a Dart. Compatible con Swift Package Manager y CocoaPods.

No la agregues a mano: `social_auth_core` la trae. Ver [doc/ios.md](../social_auth_core/doc/ios.md).
